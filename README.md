## Project Goals

This repository documents the complete workflow of an EEG-based motor intent classification project, from experimental design and signal acquisition to preprocessing, feature engineering, machine learning, and interpretation of results.

The objective is not only to present the final outcomes but also to demonstrate reproducible analytical workflows, technical documentation, and professional project organization.

## Project Overview

Brain–Computer Interfaces (BCIs) have the potential to restore communication and improve rehabilitation by translating neural activity into meaningful commands. However, accurately decoding motor intentions from electroencephalographic (EEG) signals remains a significant challenge due to their low signal-to-noise ratio and high variability.

This project investigates whether EEG signals can be used to classify voluntary lower-limb motor activity through a complete biomedical data analysis pipeline. The workflow includes experimental data acquisition, signal preprocessing, feature extraction, machine learning, and performance evaluation.

The study was developed as part of the *Design and Development in Neuroengineering* course at Tecnológico de Monterrey and focuses on distinguishing both movement laterality (right vs. left foot) and movement state (movement vs. rest).

Beyond its academic objectives, this project demonstrates practical skills in biomedical signal processing, machine learning, experimental design, and healthcare data analytics.
